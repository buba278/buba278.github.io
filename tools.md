# tools

small browser tools made for projects. they run entirely in the page, nothing gets sent anywhere.

### [sensortile live](/tools/sensortile/)
live compass, step trace and dead-reckoning trail for an st sensortile, over bluetooth or usb serial. built for a compsys 704 pedestrian tracking project. try the demo source if you don't have a board.

needs chrome or edge for bluetooth and serial.
